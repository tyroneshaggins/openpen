# Security policy

## Supported versions

Security fixes are provided for the current 1.x line.

## Reporting a vulnerability

OpenPen is a local desktop app. It does not contain networking code, accounts, update
checkers, or telemetry. Its only local writes are preferences, an optional crash log, and
screenshots you explicitly take.

If you find a security issue anyway, please use GitHub's **private vulnerability
reporting** on this repository instead of opening a public issue. Include:

- OpenPen version
- Windows version
- Steps to reproduce
- The impact you believe it has

Please do not include passwords, personal files, or other sensitive data in reports.
